## Git setup
1. git lfs install
2. git lfs track "*.png" "*.jpg" "*.psd" "*.tga" "*.wav" "*.mp3" "*.mp4" "*.mov" "*.fbx" "*.glb" "*.gltf" "*.anim" "*.prefab" "*.unitypackage"
3. git add .gitattributes
4. git commit -m "Configure Git LFS for large Unity assets"
5. git push
